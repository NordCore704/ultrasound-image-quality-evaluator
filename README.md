# Ultrasound Image Quality Assessment Toolkit

Clean, modular Python code for objective evaluation of diagnostic ultrasound image quality.  


> **Evaluation of Image Quality in Diagnostic Ultrasound Systems**

## What the code measures

| Objective | Metric(s) implemented |
|-----------|-----------------------|
| 1. Image sharpness / spatial resolution | Laplacian variance, Tenengrad, Brenner gradient |
| 2. Contrast & clarity | RMS contrast, Michelson contrast, Weber contrast |
| 3. Noise (SNR & CNR) | Simple SNR, classic CNR, alternative CNR, **gCNR** |
| 4. Brightness balance / uniformity | Coefficient of variation of block means, horizontal profile CoV |
| 5. Image flaws / artefacts | Local-variance outlier fraction (simple numeric flag) |
| 6. Compare across scans | CSV export of all metrics |
| 7. Overall quality score | Transparent weighted combination (0–100) |

## Installation

```bash
cd ultrasound_iq
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Quick start

### Interactive analysis of one image
```bash
python main.py --image /path/to/your/ultrasound.png --interactive
```
You will be asked to draw two rectangles:
1. **Target** – the structure / lesion / organ of interest  
2. **Background** – surrounding tissue (for SNR/CNR)

### Non-interactive (ROIs known in advance)
```bash
python main.py --image scan.png --target 150,90,70,55 --background 320,210,90,70
```

### Batch folder + save everything
```bash
python main.py --folder ./clinical_images/ --interactive --output results.csv --save-dir figures
```

## Output

- Printed table of all metrics  
- `*_rois.png` – image with the two ROIs drawn  
- `*_hist.png` – intensity histograms of Target vs Background  
- `*_bars.png` – bar chart of key metrics  
- `ultrasound_iq_results.csv` – one row per image (ready for statistical analysis / tables in the thesis)

## Recommended workflow for the thesis

1. Collect a set of real clinical B-mode stills (or freeze-frames from cine loops).  
2. Run the interactive mode on each image, carefully placing the Target and Background ROIs at comparable depths and avoiding calipers / text overlays.  
3. Export the CSV.  
4. In the Results chapter present the CSV summary statistics, box-plots, and example figures generated by the toolkit.

## Notes & limitations (be transparent in the thesis)

- Spatial resolution is estimated by **no-reference sharpness metrics**. True axial/lateral resolution (FWHM of point targets) requires a phantom.  
- SNR/CNR are highly dependent on ROI placement – document the placement rules.  
- Artefact detection is only a simple statistical flag; visual inspection by a sonographer remains essential.  
- The overall quality score is a pragmatic composite; justify the weights or present the individual metrics separately.

## Extending the code

All metric functions are pure and independent. We can easily add:
- DICOM loading (uncomment `pydicom` / SimpleITK in `requirements.txt`),
- more advanced uniformity tests,
- machine-learning quality predictors later.
